# Smart Campus Solutions – Srijan 2K26

A Smart Attendance Management System designed to simplify campus attendance using web technologies and Firebase.

## About the Project

Smart Campus Solutions is a web-based prototype that helps students mark attendance and allows administrators to view attendance records from a centralized dashboard.

## Features

- Student Signup and Login
- Admin Login and Dashboard
- Attendance Marking
- Cloud-based Attendance Records
- Firebase Authentication
- Firestore Database Integration
- Simple and User-Friendly Interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Cloud Firestore

## How It Works

1. Students sign up and log in.
2. Students mark their attendance through the dashboard.
3. Attendance records are stored in Cloud Firestore.
4. Administrators log in to view attendance records.

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Configure your Firebase project credentials in `index.html`.
4. Enable Firebase Authentication and configure Cloud Firestore rules.
5. Run `index.html` using the VS Code Live Server extension.

## Security

- Do not upload passwords, private keys, or service-account credentials.
- Configure Firestore Security Rules before deployment.
- Restrict student and admin access according to their roles.
